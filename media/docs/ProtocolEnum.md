# ProtocolEnum

An enumerated type that indicates whether the video streaming protocol is DASH (Dynamic Adaptive Streaming over HTTP) or HLS (HTTP Live Streaming).<br /><br />DASH is also known as MPEG-DASH. It is an internationally accepted protocol for streaming video. It splits a larger media file into much smaller segments.<br /><br />HLS is a format developed by Apple. Rather than deliver a video file all at once, HLS splits it into much smaller segments. Since HLS was developed by Apple, it is the only method of video streaming currently supported on iOS (iPad and iPhone) and is supported natively within its Mac Safari browser. | - **DASH**: The video streaming protocol is DASH (Dynamic Adaptive Streaming over HTTP). - **HLS**: The video streaming protocol is HLS (HTTP Live Streaming).

## Enum

* `DASH` (value: `'DASH'`)

* `HLS` (value: `'HLS'`)
